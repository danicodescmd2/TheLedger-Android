# The Ledger Android App

This project wraps the supplied single-file web app `bookshop-ledger-1.html` in an Android WebView.

## Build in Android Studio
1. Open this folder in Android Studio.
2. Let Gradle sync and install any requested SDK components.
3. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. The debug APK will be under `app/build/outputs/apk/debug/app-debug.apk`.

To make the requested filename, rename/copy the APK to `TheLedger.apk` after building.
